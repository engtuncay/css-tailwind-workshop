

In order for the extension to activate you must have tailwindcss installed and one of these:

- For v4 and later, a .css file that imports a Tailwind CSS stylesheet (e.g. @import "tailwindcss")
- For v3 and earlier, a Tailwind CSS config file named tailwind.config.{js,cjs,mjs,ts,cts,mts} in your workspace.
- For v3 and earlier, a stylesheet that points to a config file via @config
